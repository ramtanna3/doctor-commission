===== sudo commands

# Reload systemd to recognize new services
sudo systemctl daemon-reload

# Enable services to start on boot
sudo systemctl enable doctor-commission-backend
sudo systemctl enable doctor-commission-frontend

# Start services now
sudo systemctl start doctor-commission-backend
sudo systemctl start doctor-commission-frontend

# Check status
sudo systemctl status doctor-commission-backend
sudo systemctl status doctor-commission-frontend
